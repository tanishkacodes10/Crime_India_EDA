# Crime_India_EDA
An Exploratory Data Analysis (EDA) project on crime data in India using Python, Pandas, Matplotlib, and Seaborn to identify crime patterns, trends, victim demographics, weapon usage, case closure rates, and city-wise crime distribution.


# 📊 Crime Data Analysis – India

## 📌 Overview

This project focuses on performing Exploratory Data Analysis (EDA) on crime data from India.

The main objective is to analyze crime patterns and uncover meaningful insights related to crime types, locations, victim demographics, weapons used, case status, and crime occurrence over time.

The analysis is performed using Python and popular data analysis and visualization libraries.

---

## 🎯 Objectives

- Analyze the distribution of different crime types
- Identify cities with higher numbers of reported crimes
- Study victim age and gender distribution
- Analyze commonly used weapons
- Examine crime domains
- Analyze case closure status
- Identify crime trends across months and years
- Study crime occurrence based on time of day
- Compare crime patterns across different cities
- Discover relationships between different crime-related variables

---
